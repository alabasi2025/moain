## تغطية اختبارات الوحدات (`tests/domain.test.ts`, `tests/webm.test.ts`)
- **المال:** تحويل الريال للهللة (أرقام عربية، فواصل، كسور)، رفض المدخلات الخاطئة، النسب، التنسيق.
- **الأقساط:** توزيع FIFO، والحالات (مدفوع/جزئي/متأخر/قريب/قادم)، والدفع الزائد، والتقسيم بمجموع مطابق.
- **ربح وخسارة الدورة:** الأنماط الثلاثة لمستحق المعلمة، وعمولة الجهة لطلابها فقط، والمنسحب (محصّله يُحسب ومتبقيه لا)، والخسارة.
- **الحصص:** نافذة الدخول، والمراحل، والتداخل الزمني نصف المفتوح.
- **Range:** كل الصيغ والحالات الحدية.
- **الأمان:** PBKDF2، وتوقيع JWT (يُتحقق منه بـ HMAC من Node)، وتوحيد أرقام الجوال السعودية.
- **الوقت:** تحويل توقيت الرياض ذهاباً وإياباً.
- **WebM:** ملف «مباشر» بدون مدة (مثل MediaRecorder) ⇐ إضافة المدة **بنفس الطول بالضبط** ⇐ ffprobe يقرأ المدة الصحيحة.

## تغطية E2E (`tests/e2e.sh`)
| المحور | ما يُختبر |
|---|---|
| عام | الصفحة الرئيسية، SEO، الدخول، PWA، robots، نموذج الحصة التجريبية |
| الأمان | تحويل غير المسجلين، 401 للـ API، كلمة مرور خاطئة، **CSRF من موقع آخر**، سر Cron، الترويسات، كوكي HttpOnly |
| الصلاحيات | الطالب ⇏ الإدارة، المعلمة ⇏ المالية، الطالب ⇏ الجدولة والرفع |
| كل الصفحات | 21 صفحة إدارة + 7 معلمة + 5 طالب |
| العزل (IDOR) | المعلمة ⇏ حصص وواجبات غيرها، الطالب ⇏ حصص دورات غيره، والطالب لا يرى مفتاح مضيف الزوم |
| **توزيع القاعات** | 5 حصص متزامنة ⇐ 4 قاعات زوم **مختلفة** + 1 بث المنصة، و«زوم فقط» مع الامتلاء يُرفض |
| **التسجيلات** | رفع مجزّأ، ومنع معلمة أخرى من إكمال رفع غيرها، والعلامة المائية، و`nodownload`، وبث 200، وRange 206، **ورفض فتح الرابط مباشرة 403**، و`no-store`، ومنع غير المسجل، **والاختفاء بعد 48 ساعة** |
| الواجبات | نشر بملف، وتنزيل، وتسليم، وتصحيح، ورؤية الدرجة، **ورفض ملف exe** |
| الرسائل | الطالب ⇐ معلمته ✔، والطالب ⇐ معلمة ليست معلمته ✘ |
| المالية | تسجيل تحويل، **ومنع التكرار العرضي**، وصرف، ومصروف، وتذكير، وإنشاء دورة وطالب ودخوله |
| الخروج | إلغاء الجلسة فعلياً في الخادم |
