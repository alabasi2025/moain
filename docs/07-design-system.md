# نظام التصميم v2 — إضاءات

## المبادئ
| المبدأ | التطبيق |
|---|---|
| شبكة 4/8px | كل المسافات مضاعفات 4px (`.25rem`) |
| تباين WCAG AA | النصوص ≥ 4.5:1 على `--surface` في الوضعين |
| أهداف لمس ≥ 44px | الأزرار والحقول `min-height: 42–56px`، التنقل السفلي 52px |
| حركة 150–400ms | `--t-fast` 140ms، `--t` 220ms، `--t-slow` 420ms؛ كلها تتوقف مع `prefers-reduced-motion` |
| RTL أصلي | خصائص منطقية (`inset-inline`, `margin-inline`)، والأسهم تُعكس بـ `.flip` |
| أرقام جدولية | `.num` = `tabular-nums` + `direction:ltr` معزول |

## الخطوط (مستضافة ذاتياً — صفر طلبات خارجية)
- **Alexandria** (متغيّر 100–900) للعناوين `--font-display`.
- **IBM Plex Sans Arabic** (400–700) للنص `--font`.
- `unicode-range` يحمّل الجزء العربي/اللاتيني المطلوب فقط، و`preload` لأهم ملفين.

## الأيقونات
- مكتبة **Lucide** (ISC) مضمّنة كـ SVG من الخادم: `src/views/icons.gen.ts` (مولّد).
- لإضافة أيقونة: أضف اسمها في `scripts/gen-icons.mjs` ثم `node scripts/gen-icons.mjs`.
- الاستخدام: `<Icon name="wallet" />`، أو مربع ملوّن `<IconTile name="wallet" tone="ok" />`.
- ⚠️ تُرسم عبر `raw()` وليس `dangerouslySetInnerHTML` (Hono يغلّف `<svg>` بسياق داخلي فيرمي خطأ).
- ممنوع الإيموجي في الواجهة (يختلف شكله بين الأنظمة)؛ اختبار `tests/render.test.tsx` يتحقق.

## الألوان (التوكنز في `:root` و `:root[data-theme='dark']`)
`--brand` بنفسجي • `--accent` كهرماني • حالات: `ok` `bad` `warn` `info` `teal` `pink` `gray`
ولكل حالة ثلاث درجات: الأساس، `-50` للخلفية، `-ink` للنص. الوضع الداكن مصمم يدوياً (أسطح كحلية متدرجة لا أسود).

## الحركة
| العنصر | الحركة |
|---|---|
| دخول الصفحة | `rise` متتابع لأبناء `.content` |

## القوائم الطويلة (v2.1)
| القاعدة | السبب |
|---|---|
| **ترقيم صفحات** (20 صفاً) بدل التمرير اللانهائي | لوحات الإدارة مهام بحث ومقارنة: موضع ثابت، رابط قابل للمشاركة، وزر الرجوع يعيدك لنفس الصفحة (NN/g) |
| ترقيم من الخادم (`LIMIT/OFFSET` + `COUNT`) للجداول الكبيرة | الجوال لا يستقبل مئات الصفوف |
| «عرض 21–40 من 143» + أرقام بنافذة ≤ 7 عناصر | يعرف المستخدم حجم القائمة، والسطر لا يلتف على الجوال |
| شريط أدوات (بحث + فلتر) أعلى كل قائمة | الوصول للعنصر بدل التصفح |
| الروابط تحافظ على البحث والفلاتر | `pageHref()` في `src/lib/paging.ts` |
| **الجداول ⇐ بطاقات** تحت 700px | نمط تطبيقات الهاتف: «العنوان: القيمة»، بلا تمرير أفقي. تحسين تدريجي عبر `app.js` (`data-label`)؛ استثنِ جدولاً بـ `.keep-table` |
| المؤشرات 2×2 على الجوال | كثافة معلومات مناسبة للشاشة الصغيرة |

## صور الملف الشخصي
- القص والتصغير في المتصفح (`public/static/avatar.js`): سحب، قرص بإصبعين، عجلة، لوحة مفاتيح ⇐ 320×320 WebP (~3–40KB).
- الخادم يتحقق من التوقيع الفعلي للملف (magic bytes) والحجم ≤ 400KB، ويخزن في R2 (`avatars/{id}`).
- `avatar_v` (رقم نسخة) يكسر التخزين المؤقت ⇐ `Cache-Control: private, immutable`.
- الصورة خلف تسجيل الدخول فقط. المستخدم يغيّر صورته من `/me`، والإدارة من صفحة أي مستخدم.
- المكوّنات: `<Avatar id v name />` و `<Person />` لخلايا الجداول.
