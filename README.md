# منصة إضاءات التعليمية 🌟

منصة ويب متكاملة لدروس التقوية المباشرة: **حصص مباشرة (زوم + بث خاص)، تسجيلات محمية تبقى 48 ساعة، واجبات، رسائل داخلية بدل الواتساب، ونظام مالي كامل** (أقساط، متأخرات، ربح وخسارة لكل دورة، مستحقات المعلمات والجهات).

> تعمل على الجوال والآيباد واللابتوب من المتصفح، وتُثبَّت كتطبيق (PWA). تكلفة التشغيل الشهرية ≈ 25 ريال.

## ✨ المزايا

### 🎥 الحصص
- **توزيع تلقائي لقاعات الزوم الأربع** على الحصص بدون أي تعارض؛ وعند امتلائها تتحول الحصة تلقائياً إلى **بث المنصة الخاص** (Jitsi) — وداعاً للزوم المجاني وحد الـ 40 دقيقة.
- رابط الحصة لا يظهر إلا للطلاب المسجلين في الدورة، ولا يظهر إلا في وقتها (من 15 دقيقة قبل البداية).
- بث المنصة داخل الصفحة نفسها، ومحمي بتوكن JWT لكل حصة: المعلمة مشرفة، والطالب مشارك.
- جدولة متكررة أسبوعياً، ومراقبة للإدارة: «الحصص الآن» وحالة كل قاعة.

### 🎬 التسجيلات
- المعلمة تسجل من المتصفح بضغطة زر، **ويُرفع التسجيل أثناء الحصة** على أجزاء إلى Cloudflare R2، فلا يضيع لو انقطع النت أو أُغلق المتصفح.
- أو ترفع ملف تسجيل الزوم بعد الحصة.
- **يبقى 48 ساعة ثم يُحذف تلقائياً.**
- مشغل محمي: بدون زر تحميل، **وعلامة مائية متحركة باسم الطالب ورقمه**، والرابط المباشر للفيديو مرفوض، وبدون تخزين مؤقت، مع سجل مشاهدات.

### 📝 الواجبات · 💬 الرسائل
- واجبات بملفات، وتسليم الطلاب، ثم التصحيح والدرجة والملاحظة، مع تنبيه التأخير.
- رسائل داخلية: الإدارة ⇔ الجميع، والمعلمة ⇔ طلاب دوراتها فقط.

### 💰 المالية
- جدول أقساط لكل طالب، وتسجيل التحويلات (المبلغ والمرجع والطريقة)، ومنع تكرار التسجيل العرضي.
- **متابعة تلقائية:** متأخر / يستحق خلال 7 أيام / مدفوع جزئياً، مع زر **تذكير** يُرسل رسالة للطالب داخل المنصة.
- **ربح وخسارة كل دورة:** المحصّل − مستحق المعلمة − مستحق الجهات − المصروفات = صافي الربح وهامشه.
- **مستحق المعلمة:** نسبة من المحصّل، أو مبلغ لكل طالب، أو مبلغ ثابت للدورة، مع سجل صرف والرصيد المتبقي.
- **مستحقات الجهات:** عمولة لكل جهة جلبت طالباً، مع سجل صرف.
- المصروفات (عامة أو على دورة)، وتقارير قابلة للطباعة، وتصدير CSV يفتح في Excel بالعربي.

### 🌐 الموقع التعريفي
- صفحة هبوط بأسلوب 51Talk، ونموذج «احجز حصة تجريبية» يصل للإدارة، وتهيئة SEO كاملة، وتصميم متجاوب بالكامل.

## 🧱 التقنيات

| الطبقة | التقنية |
|---|---|
| الخادم | [Hono](https://hono.dev) على Cloudflare Pages Functions (TypeScript + JSX من الخادم) |
| قاعدة البيانات | Cloudflare D1 (SQLite) |
| الملفات والتسجيلات | Cloudflare R2 (بدون رسوم تحميل) |
| البث الخاص | Jitsi Meet مستضاف ذاتياً (Docker) على VPS، مع JWT |
| الواجهة | HTML من الخادم + CSS مخصص (RTL) + JavaScript خفيف بدون أطر |
| الاختبارات | Vitest (وحدات) + سكربت E2E على الخادم الفعلي |

## 🚀 التشغيل المحلي

```bash
npm install
cp .dev.vars.example .dev.vars      # أضف DEMO_MODE=1 لإظهار أزرار الحسابات التجريبية
npm run db:reset                    # إنشاء الجداول + بيانات تجريبية
npm run build
npm run preview                     # http://localhost:3000
```

**الحسابات التجريبية** (كلمة المرور لكلها: `demo1234`):

| الدور | الجوال |
|---|---|
| الإدارة | `0500000001` |
| معلمة | `0510000001` … `0510000014` |
| طالب | `0550000001` … `0550000040` |

## ☁️ النشر
راجع [docs/03-deployment.md](docs/03-deployment.md). باختصار:
1. `wrangler d1 create edaat-db` و`wrangler r2 bucket create edaat-media`، ثم ضع `database_id` في `wrangler.jsonc`.
2. `npm run db:migrate:prod`، ثم `npm run deploy`.
3. على السيرفر السحابي: `DOMAIN=meet.example.com EMAIL=you@x.com bash deploy/jitsi/install.sh`.
4. ضع `JITSI_DOMAIN` و`JITSI_APP_SECRET` في مشروع Cloudflare، ثم أعد النشر.

  routes/
    public.tsx           الموقع التعريفي، الدخول، PWA

deploy/                  سكربت تركيب Jitsi، Worker التنظيف المجدول، قاعدة Lifecycle لـ R2
